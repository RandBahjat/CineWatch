Know exactly what your viewers do.

API reference

Two endpoints. Nine parameters.

Everything is driven by the URL — no API keys, no SDK, no build step. Append query parameters to tailor the player to your product.

MovieGET
https://mapple.fun/watch/movie/{tmdb_id}TMDB ID

Example: /watch/movie/181812

TV episodeGET
https://mapple.fun/watch/tv/{tmdb_id}TMDB ID-{season}Season-{episode}Episode

Example: /watch/tv/83867-1-1

  • autoPlayboolean

    Start playback as soon as the player loads.

    autoPlay=true
  • startAtnumber

    Start the video at the given time, in seconds.

    startAt=120
  • themehex

    Accent color for controls, without the leading #.

    theme=16A085
  • titleboolean

    Show the media title overlay.

    title=true
  • posterboolean

    Show the poster image before playback.

    poster=true
  • nextButtonbooleanTV only

    Show a “Next episode” button after 90% of the episode.

    nextButton=true
  • autoNextbooleanTV only

    Play the next episode automatically (needs autoPlay).

    autoNext=true
  • watchPartyboolean

    Show the watch party button for synced viewing.

    watchParty=true
  • partyIdstring

    Join an existing watch party room.

    partyId=DIHQQ3
